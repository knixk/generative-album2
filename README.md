# generative-album2
 IMPORTANT:
 the app will show a blank screen if u open it for the first time.
 You need to configure it.

inroder to do so,
you need to go to the /config page.
and fill the details accordingly

flow:
user goes to the / page,
click the call to action button,
goes to the second screen,
fills the form,
hits enter.


on a seperate window, the /album page should be opened,
once the image is generated, it should reflect this page.

keep in mind we can customize the fields we want the user to fill,
so it's a very customizable picture.

also the home page image, text, prompts, header text,
all are customizable
